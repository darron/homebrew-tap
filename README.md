# Darron's Homebrew Tap

Homebrew formulae for tools published by Darron.

## Install dbrain

```sh
brew install darron/tap/dbrain
```

Or tap once and install by formula name:

```sh
brew tap darron/tap
brew install dbrain
```

## Brewfile

```ruby
tap "darron/tap"
brew "dbrain"
```

## Documentation

Run `brew help`, `man brew`, or read Homebrew's documentation:
https://docs.brew.sh
